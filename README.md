# Arnold Moesses · Portafolio profesional

Sitio estático (HTML, CSS y JavaScript) sin dependencias de compilación.

## Estructura
- `index.html`, `proyectos.html`, `acerca.html`, `contacto.html`
- `css/` estilos, adaptación a móvil y animación de portada
- `js/` menú, filtro de proyectos y formulario de contacto
- `assets/img/perfil/arnold.jpg` tu foto (pendiente de agregar)

## Cómo verlo
Abre `index.html` en el navegador. Requiere internet para cargar la fuente Inter y los iconos Lucide.

## Publicarlo gratis
Sube la carpeta a un repositorio de GitHub y activa GitHub Pages (Settings → Pages), o arrástrala a Netlify.

## Pendientes
- Agregar la foto en `assets/img/perfil/arnold.jpg` (mientras tanto se muestra el monograma AM).
- Reemplazar los fondos de color de los proyectos por capturas reales (`.project-one` … `.project-six` en `css/styles.css`).
- El formulario abre tu correo con el mensaje listo; para recibirlos directo se puede conectar Formspree o similar.
